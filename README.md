# Aventurine Array

Full-colour Python 3 neon laser-mirror arcade for [ElbowOS](https://x.com/ElbowOS).

A gold emitter at the top of a vertical chamber fires a mint beam.
Rotate five aventurine plates so the beam ricochets into drifting gems.
W / S select a plate. A / D rotate. R resets.

## Play

```
pip install -r requirements.txt
python3 aventurine_array.py --play
```

## Record a 9:16 reel

```
python3 aventurine_array.py --record
```

Writes `AVENTURINE_ARRAY_ElbowOS.mp4` (1080×1920, 15 s, 30 fps, H.264).
